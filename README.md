Aby projekty działały poprawnie, po pobraniu repozytorium należy użyć komendy

## Project02
Program obsługuje 3 kombinacje (scieżka + metoda)

1. GET /
2. GET /nazwa obiektu(jesli nazwa ma spacje nalezy dodać znak "_")
3. POST /new(który służy do dodania nowych obiektów)

Po włączeniu programu użytkownik zaczyna na 1 obslugiwanej kombinacji. Może użyć linku bądź wpisac w adres URL nazwe obiektu aby skorzystać z 2 kombinacji, Bądź wypełnić formularz dodania nowego obiektu aby skorzystać z 3
## Project03

Strona pozwalająca wyszukać karty Yu-Gi-Oh! TCG i dodać je do bazy danych jako karty posiadane.

Strona wyszukuje karty poprzez korzystanie z [YGOPRODeck API](https://ygoprodeck.com/api-guide/).

## Project04

Ulepszona wersja [Project03](#project03), Pozwalająca założyć konta użytkowników.

Strona tworzy również konto administratora, które potrafi edytować i usuwać dane innych użytkowników.

Konto administratora jest tworzone przy pierwszym włączeniu strony.

Strona wyszukuje karty poprzez korzystanie z [YGOPRODeck API](https://ygoprodeck.com/api-guide/).
